# McKim-et-al-2026-Synaptic-connectome-of-a-neurosecretory-network-in-the-Drosophila-brain

R and Python code to replicate connectomic figures and analyses from: <br>
McKim et al. (2026) Synaptic connectome of a neurosecretory network in the *Drosophila* brain<br>
https://doi.org/10.7554/eLife.102684
<br>
<br>
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.16747141.svg)](https://doi.org/10.5281/zenodo.20795211)


## Getting Started
1. Download this repository<br>
2. Go to zenodo and download all files needed to be placed into `input/` directory<br>
3. Use the included R Project file (`NSC_Connectome.Rproj`) to access and run the scripts
<br>

Instructions and folder layout are also found in the README_FolderStructure document
